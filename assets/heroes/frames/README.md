# Cozy Arena original-character animation frames

Four heroes: knight, archer, mage, healer. Each has 6 idle PNG frames and 8 attack PNG frames, all transparent RGBA at exactly the same pixel dimensions as the original source PNGs. Source files remain unchanged.

View preview.png to compare the attack frames side by side. Animation FPS and file paths are in manifest.json.

These are cutout/transform frames from the original idle and attack poses, not individually redrawn limb animations. The live game currently uses its old two-pose system until an animation loader is integrated.
